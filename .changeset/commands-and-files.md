**Commands that keep running, approvals that remember, file tools in Docker.** An Agent can start a command in the background (`bash` with `background: true`): a dev server, a watcher, a long build. The daemon keeps it past the turn, the Agent reads its output, types into it, interrupts or stops it (`job_output`, `job_input`, `job_stop`, `job_list`), and when it ends the Agent is woken in the conversation that started it with how it ended. **Background jobs** in the Agent's panel and `bazilion job list|show|stop` show them, with Stop. A dangerous command can now be allowed for good: **Always for this Agent** (on the card, `a` in a terminal chat, **Always** on Telegram) keeps a rule for its beginning, such as `git push`, for single simple commands; the rules are on the Tools page and in `bazilion approval rules|rm`. **Dangerous commands** on the Commands card gains **A review model first**: the Command review model on the Models page allows, refuses or passes each one to you. In Docker mode `read`, `write`, `edit`, `grep`, `find` and `ls` now work on the container's paths, and `apply_patch` applies one patch across several files in both modes. Upgrading adds one table; the daemon migrates the home when it starts.
