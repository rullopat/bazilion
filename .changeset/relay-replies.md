**An Agent tells you what a teammate brought back.** When a teammate answered work an Agent had handed out, the Agent was told "no response is required", and it sometimes ended its turn without a word. The answer then stayed in a closed teammate update, and the files it named never reached Files. Now the Agent still sends nothing back to the teammate, but tells you in a few lines what came back. It also delivers the files the reply names, so they show in Files.
