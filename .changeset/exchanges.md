**Agents can work together as long as the work needs: exchanges between them have no length limit.** A chain of messages used to stop after eight replies, even when it was real work. Now an exchange stops only when its Agents go round in circles (one sends another the same message again: it is not delivered, and the Agent is told to tell you where things stand) or when you stop it. A woken Agent also reads the exchange so far and ends it when it no longer moves the first request forward. While an exchange goes on, the Connections tab shows it under **Going on now**, with how many messages, since when and what it has used, and a **Stop** button; `bazilion inbox exchanges <team>` and `bazilion inbox stop <exchange>` do the same. The **Messages between Agents** setting is gone, and `bazilion inbox loop-breaks` is now `bazilion inbox stopped`.
