**Secrets an Agent asks for, kept out of the conversation.** When an Agent needs an API token or a password, it asks for it by name with `secret_request` instead of having you paste it into the chat. On the web you get a card with a masked field (**Store**, or **Decline** with a note); on Telegram, which cannot mask a message, a link to it and **Decline**; in a terminal, `bazilion agent secret set <agent> <NAME>` reads it without echo (`--from-file` for a key file). The Agent is told only that it was stored or declined. Its commands get the secret as an environment variable of that name, on the host and in Docker, and `web_fetch` takes request headers, filling in `{{secret:NAME}}` only for the hosts the secret was given for and dropping the Agent's headers on a redirect to another site. Tool output now reaches the model and the transcript with these secrets, and Bazilion's own credentials, taken out. Each Agent's secrets are encrypted with Bazilion's own keys, listed (never shown) on its new **Secrets** sheet with **Replace** and **Remove**, and in `bazilion agent secret list|set|rm`; they are deleted with the Agent. Nothing changes in the database's schema.
