**The Agent works in the workspace with you.** It can open a place for you (`screen`): the Changes or Files tab after it changed or made files, a full-width view, its schedules or jobs, in the browser tabs that show its conversation, never in a tab showing something else. It can switch the theme when you ask (`theme`). For a long task it keeps one progress card in the conversation (`progress`), updated as steps start, finish or fail, which is one edited message on Telegram. And it can show a small HTML page or SVG drawing right in the chat (`canvas`), a chart or a table, in a sealed frame that runs its scripts but has no network and no access to Bazilion; HTML and SVG files it delivers show the same way instead of only downloading, with a button for full size.
