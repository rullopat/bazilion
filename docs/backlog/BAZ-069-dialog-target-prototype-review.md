## Findings before enabling any exception

1. **P1, measurement trust:** a page can wrap page-realm `Map.prototype.get` and change `JSON.stringify` to mutate the seal's serial and supply its previous baseline. A frozen exported API does not secure its mutable dependencies. The reviewer reproduced acceptance of changed dialog text in memory; the parent then reproduced it in the actual browser.
2. **P1, incomplete rendering:** island-descendant styles do not cover ancestor compositing or all pseudo-element styling. The parent independently confirmed an outside text change can activate `body:has(...){opacity:0}` while `unchanged()` returns true.
3. **P1, outside context is not necessarily unrelated:** ordinary explanatory text just outside a dialog can change its consent meaning without ARIA linkage. A same-size dialog is not a justified semantic boundary. Both the review harness and actual-browser fixture accepted this changed context.
4. **P1, behavior/dispatch:** event handlers or their backing JavaScript state can change without DOM records. The parent confirmed direct `onclick` replacement returns true. Checking a center point is also not an atomic binding to a later click: actionability, scrolling, hover and the eventual locator/target require their own design. DOM evidence cannot prove arbitrary hostile JavaScript honors a label.
5. **P1, observation publication:** the prototype accepts a stats argument, not a daemon-owned published observation/session/tab/action tuple. Reading fresh stats after an old snapshot can seal text the Agent did not see. This was explicitly an unresolved integration question, not a runtime exemption.
6. **P2, unknown coverage:** closed shadow roots are invisible through `.shadowRoot`; CSSOM, canvas and live state are not comprehensively covered. The parent reproduced closed-shadow explanatory changes accepted by the prototype.
7. **P2, retained memory:** 128 mutation records are not a byte bound on their referenced DOM graphs. A detached ancestor subtree can remain reachable through a retained node. Documentation now distinguishes serialized-string limits from DOM/native memory.
